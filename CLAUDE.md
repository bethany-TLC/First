# Repo Purpose

This repo is Bethany's personal "claude brain" — an archive of her LLM conversation exports (Claude, ChatGPT, etc.) so that Claude Code sessions can pick up context about her, her business, and past conversations instead of starting cold.

## Before starting work

Check `claude-brain/` for relevant context:

- `claude-brain/claude-export/conversations.json` — full Claude.ai conversation history
- `claude-brain/claude-export/memories.json` — Claude.ai saved memories
- `claude-brain/claude-export/projects/` — Claude.ai project data
- `claude-brain/chatgpt-export/` — ChatGPT chat exports

These files are large; grep/search for relevant terms rather than reading them in full. This content is personal and sensitive (business details, private conversations) — treat it accordingly and don't repeat it back verbatim unless it's directly relevant to the task at hand.
