# Repo Purpose

This repo, Bethany-OS, is Bethany's personal knowledge base and "brain" — organized business knowledge about her, The Luxora Collective, and past conversations, plus the raw LLM export archive it's distilled from. Claude Code sessions should use it to pick up real context instead of starting cold.

## Before starting work

1. Read `ABOUT_BETHANY.md` and `LUXORA_PLAYBOOK.md` for a fast overview.
2. Check the relevant category folder for organized material: `knowledge/`, `prompts/`, `frameworks/`, `sales/`, `marketing/`, `operations/`, `hiring/`, `podcasts/`, `content/`, `case-studies/`, `templates/`, `sops/`, `ai-agents/`.
3. If nothing organized covers what you need, search `archives/` — the raw export:
   - `archives/claude-export/conversations/` — every Claude conversation, one file each, with `_index.json` listing titles/dates
   - `archives/claude-export/memories.json` — Claude.ai saved memories
   - `archives/claude-export/projects/` — Claude.ai project data
   - `archives/chatgpt-export/conversations/` — every ChatGPT conversation, one file each, with `_index.json` listing titles/dates
   - `archives/chatgpt-export/attachments/` — a partial set of files attached within ChatGPT conversations (not exhaustive)

`archives/` is large; grep/search for relevant terms rather than reading it in full. When you find something useful there, consider pulling it into the right category folder so it's easier to find next time.

This content is personal and sensitive (business details, private conversations) — treat it accordingly and don't repeat it back verbatim unless it's directly relevant to the task at hand.
