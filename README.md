# Bethany-OS

Bethany's personal knowledge base and "brain" — organized business knowledge plus the raw archive it's distilled from, so Claude Code sessions can pick up real context instead of starting cold.

## Layout

- `CLAUDE.md` — instructions for Claude Code sessions working in this repo
- `ABOUT_BETHANY.md` — who Bethany is, personally and professionally
- `LUXORA_PLAYBOOK.md` — what The Luxora Collective does and how
- `knowledge/` — general reference material
- `prompts/` — reusable LLM prompts and custom instructions
- `frameworks/` — named methodologies (Revenue Leak Audit, Market Blueprint, etc.)
- `sales/` — scripts, objection handling, closer SOPs
- `marketing/` — ad copy, campaigns, positioning
- `operations/` — internal ops, team structure, financials
- `hiring/` — job descriptions, contracts, assessments
- `podcasts/` — podcast content and planning
- `content/` — blog/social/long-form content
- `case-studies/` — client results and case study library
- `templates/` — reusable document templates
- `sops/` — standard operating procedures
- `ai-agents/` — AI tooling and workflow setups
- `archives/` — raw Claude and ChatGPT conversation exports (source material everything above gets distilled from)

## How this works

`archives/` is the unfiltered record — every Claude and ChatGPT conversation, split one-per-file. The other folders are the organized, curated layer built from it. When something useful shows up in `archives/`, pull it out into the right category folder above rather than leaving it buried in raw export files.
